# 分数マスター ✕ 冒険

分数同士のかけ算・わり算を、ステップで考えながら解いていく冒険型の学習ゲームです。XPをためてレベルと称号を上げ、バッジを集めながら進みます。

## 公開ページ

[GitHub Pagesで開く](https://tt-sensei.github.io/-bunkakebunwari/)

## モード

- かけ算：分数 × 分数
- わり算：分数 ÷ 分数

1回10問です。

## 解き方（ステップ方式）

問題は「ステップで解こう」で手順を1つずつ進めてから、最後に答えを入力します。答えだけを当てるのではなく、途中の考え方（約分するかどうか、ひっくり返すかどうかなど）を確かめながら解けます。

## とっくん（間違えた問題の記録）

- ステップでつまずいた問題や、答えを間違えた問題は、端末内（localStorage）に自動で記録されます
- タイトル画面の「とっくん」から、記録された問題をそのまま出題します（最大10問）
- とっくんで正解できたら、その問題は記録から消えます（克服）

## 音のON/OFF

- タイトル画面の「♪ 音 ON／OFF」ボタンで効果音を切り替えられます。設定は端末に保存されます

## レベルとバッジ

- 正解でXPがたまり、レベルアップで称号が変わります（見習い計算士、計算の剣士など）
- 条件を満たすとバッジがもらえ、「バッジ図鑑」でコレクションを確認できます
- ハイスコアが記録されます

## 対象

小学校6年生（分数のかけ算・わり算）。

## 技術メモ

- `index.html` の単一ファイルで動作し、ビルド不要
- 記録は端末内（localStorage）に保存
